# Ruby Basics - The Odin Project

Four introductory Ruby exercises from the Basic Ruby Projects section.

## Projects
- **Caesar Cipher** - string manipulation, character shifting
- **Substrings** - substring matching within a string, filtering with `reduce`
- **Stock Picker** - array iteration, index tracking
- **Bubble Sort** - sorting algorithm implementation

## Running tests
Caesar Cipher has RSpec tests:

    cd caesar-cipher
    bundle exec rspec
